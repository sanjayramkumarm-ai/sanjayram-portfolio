# Sanjayram CK - Portfolio 2026

A single-file portfolio site (HTML, CSS, JavaScript). No build step needed.

## Run locally
Open `index.html` in a browser, or run `npx serve .` in this folder.

## Deploy
Drag this folder to Netlify, or run `vercel` in it.

## Before going live
- In `index.html`, set `var EMAIL=""` in the script to your real email to enable the contact form.
- Replace the "Preview placeholder" boxes in the Works section with real screenshots.
- Add your LinkedIn link in the Contact section when ready.
